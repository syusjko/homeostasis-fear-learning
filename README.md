# 항상성 기반 위협/공포 학습 — 최소 아키텍처 탐구

> "어텐션이 간결한 선형대수 공식 하나로 세상을 지배했다면, 의식/의지도 그런 최소한의
> 규칙으로 설계할 수 있을까?"라는 질문에서 출발해, 실제로 검증 가능한 좁은 질문
> ("공포 학습의 행동적 서명이 이 최소 규칙에서 창발하는가")으로 좁혀 온 과정의 기록.

## 이 레포가 답하지 않는 것 / 답하려는 것

**답하지 않는다**: "이 시스템에 의식/의지가 있는가." 이건 애초에 행동만으로는
검증 불가능하다는 결론에 도달했다 (좀비 논증, `docs/DESIGN_JOURNEY.md` 3장 참고).

**답하려는 것**: 동물의 공포에서 관찰되는 네 가지 행동적 서명 — ① 빠른 반사
② 일반화(정확히 같은 자극이 아니어도 위협 범주 근처면 회피 전이) ③ 소거/재발
④ 위협 기억의 비대칭적 보존 — 이 극도로 단순한 규칙 집합(항상성 자원 + 예측오차 +
프로토타입 기반 반사, 명시적 계획 없음)에서 창발하는가?

## 핵심 설계 원칙 (여러 라운드의 비판을 거쳐 남은 것)

1. **온라인 학습(fast weights)과 진화(slow weights)를 분리**한다.
   `W_t = λW_{t-1} + η(e_t ⊗ h_{t-1})` 형태의 국소(local) Hebbian 갱신이 생애 내
   적응을 맡고, 스칼라 하이퍼파라미터만 세대 간 변이·도태로 진화한다.
2. **볼드윈 효과 방지**: 생애 동안 학습으로 바뀌는 것(가중치, 프로토타입 위치)은
   유전자형에 넣지 않는다. 모든 개체는 공통 초기값(`W_0=0`, 빈 프로토타입 집합)에서
   시작한다. 이 원칙을 어기면(예: 프로토타입 초기 위치를 유전) 선택압이 실제
   대상이 아니라 "빨리 수렴하는 능력"에 걸려 진화가 정체된다.
3. **위협 기억은 eligibility trace + 흥분성/억제성 연관의 분리**로 구현한다.
   흥분성 연관만 있으면 소거가 불가능하고, 억제성 연관을 따로 둬야 "소거 후
   무관한 스트레스로 재발"하는 현상이 재현된다.
4. **불확실성과 반대 유인(보상)이 함께 있어야 진짜 식별이 창발한다.** 위협이
   항상 확정적으로 피해를 준다면, "묻지도 따지지도 않고 회피"가 진화적으로
   최적이 되어 일반화·소거 실험 자체가 무의미해진다 (`threat_fear_sim` 참고).
5. **내수용감각(interoception)을 표상에 직접 연결해야 한다.** 항상성 상태
   `v_t`가 은닉 상태 `h_t` 계산에 입력되지 않으면, "배고픈 상태"와 특정 자극의
   조합을 학습할 방법이 원천적으로 없다.

## 상태: 무엇이 검증됐고 무엇이 안 됐는가
