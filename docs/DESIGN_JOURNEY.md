# 설계 여정 요약

전체 대화는 훨씬 길고 우회적이었지만, 실제로 살아남아 코드에 반영된 결정과
그 이유만 추렸다. 시간순.

## 1. 출발점과 기각된 것

**질문**: 어텐션(`softmax(QK^T/√d)V`)처럼 극도로 간결한 공식 하나로 스케일업
가능하고, 실시간으로 가중치가 바뀌며, 자율적 의지를 가진 것처럼 보이는 AI를
설계할 수 있는가?

**기각된 접근들과 이유**:
- *단일 오차 신호로 전부 통합* (`e_t = h_t - W_{t-1}h_{t-1}` 하나로 가중치 갱신,
  동기, 자기관조까지 처리) — 표상 붕괴(모든 것을 상수로 만들어 오차를 속이는
  자명해)를 막을 정규화가 필요해지는 순간 "두 줄짜리 뼈대"라는 전제가 깨진다.
- *순수 선형 재귀만으로 스케일업* — 메모리 용량(rank-1 업데이트의 간섭),
  게이팅 부재, 비선형 표현력 부족, 학습 안정성이 실제 연구(Mamba, DeltaNet 등)
  에서도 게이팅·MLP·정규화를 덧붙여야 겨우 해결되는 문제들이라, "순수하게
  간결한 뼈대"는 애초에 실전에서 성립하지 않는다.
- *설계 vs 창발이라는 이분법* — 자연선택도 결국 최적화 과정이므로 "설계되지
  않고 저절로 생겼다"는 창발은 동물에게도 없다. 진짜 구분선은 "목적함수에서
  행동까지의 거리와 매개 표상의 풍부함"이다.

## 2. 검증 기준을 좁히다

의식/의지를 직접 증명할 방법이 없다는 걸 인정하고(좀비 논증), 대신 **동물과
인간이 두려움을 느낄 때 보이는 행동적 서명**과 비교하기로 함:
① 빠른 반사 ② 일반화 ③ 소거/재발 ④ 위협 기억의 우선 보존.

이 기준도 완벽하지 않다 — 행동 서명이 일치해도 "정말 느끼는가"는 여전히
증명 불가. 다만 "행동 패턴이 리워드 셰이핑으로 직접 심어진 게 아니라, 목적함수
와 행동 사이의 먼 거리를 통해 간접적으로 나왔는가"가 최소한의 신뢰 기준이 된다.

## 3. 최소 설계로 수렴

- 목적함수는 극도로 희소하게(생존 시간만), 행동 규칙은 세부 지정하지 않는다.
- fast weights(개체 생애 내 학습, eligibility trace 기반 국소 갱신)와
  slow weights(세대 간 변이·도태, gradient 없음)를 분리한다.
- 항상성 자원을 벡터(에너지·무결성·호기심)로 두어 다중 동기 경쟁이 표상 공간
  안에서 자연히 생기게 한다.

## 4. 반복적으로 걸린 함정들 (자세한 내용은 `LESSONS.md`)

- 프로토타입 초기 위치를 유전자형에 넣어 볼드윈 효과 재발 → 제거.
- 망각율을 단일 상수로 둬서 "위협 기억이 더 오래간다"는 서명이 구조적으로
  불가능했음 → 자원별 비대칭 감쇠 도입.
- eligibility trace를 "직전 상태 하나"로 근사해서 시간적 신용 할당이 실제로는
  사후 클러스터링과 다르지 않았음 → 감쇠형 trace로 수정.
- 첫 토이 시뮬레이션에서 위협이 확정적 피해를 주자 "묻지마 회피"가 진화적
  최적이 되어 일반화·소거 실험 자체가 무의미해짐 → 확률적 위협 + 호기심 자원
  (반대 유인) 도입.
- 항상성 상태가 은닉 표상 계산에 입력되지 않아 "배고픔"을 표상할 방법이 없었음
  → 내수용감각 항 추가.

## 5. 다개체 사회적 신호 실험으로 확장

포식자/독초를 구별하는 경보 신호가 진화하는지 검증하는 과정에서, 결과 자체보다
**통계 방법론의 함정**이 더 중요한 발견이 됨 — 자세한 내용은 `LESSONS.md` 참고.
요약: 신호가 회피 행동에 영향을 준다는 것 자체는 여러 시드에서 견고했지만,
"어떤 유전자가 구별 능력과 상관있는가"라는 세부 결론은 방향성 버그와 표본
2개짜리 이상치 때문에 대부분 착시로 판명됨.

## 6. "의지 게이트" 신경망 실험 — 미해결로 남은 지점

느린/빠른 가중치 이분법을 떠나, ES(진화 전략)로 학습되는 신경망 정책에 "본능
네트워크"와 별도의 "의지 게이트 네트워크"를 병렬로 얹어 행동/신호를 조절하게
하는 실험으로 확장. 여기서 반복적으로 발견된 문제:

- 다중 시드 비교에서 시드가 실제로 적용되지 않는 버그(초기화 함수 내부에
  하드코딩된 seed가 외부 seed를 덮어씀).
- 천적이 사실상 움직이지 않아 조우 자체가 거의 발생하지 않음(도망 임계값이
  공포 0인 상태에서도 이미 18% 확률로 발동).
- **가장 근본적으로**: ES 훈련이 소프트맥스 샘플링으로만 진행되어, "상태를
  무시하고 특정 행동의 로짓을 근소하게 1위로 유지하는" 결함 정책이 훈련 중
  샘플링 노이즈 덕분에 벌점을 받지 않음. 그 결과 결정론적(argmax) 정책은
  상태와 무관하게 하나의 행동(EAT)으로 완전히 붕괴하는데, 확률적 평가 지표는
  이 결함을 계속 가려서 여러 라운드에 걸쳐 원인이 드러나지 않았음.

마지막 시도(v11)는 훈련 롤아웃에 온도 어닐링(세대가 진행될수록 argmax에
가깝게)을 적용해 이 불일치를 직접 겨냥했지만, **실행/검증되지 않은 채
대화가 종료됨**. 다음 작업자가 우선 확인해야 할 지점.
